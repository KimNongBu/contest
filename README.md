# 울산대 학과 공지사항 디스코드 알림 봇

새 공지가 올라오면 디스코드로 알려주는 봇입니다. GitHub Actions로 1시간마다 돌아가고, 비용은 들지 않아요.

## 설치 (10분)

1. **디스코드 웹훅 만들기**
   알림 받을 채널 → 채널 편집(⚙️) → 연동 → 웹후크 → 새 웹후크 → **웹후크 URL 복사**

2. **GitHub 저장소 만들기**
   GitHub에서 새 저장소(Public 권장: Actions 무료 무제한)를 만들고 이 폴더 파일을 전부 올립니다.
   `.github/workflows/notice.yml` 경로가 그대로 유지되어야 해요.

3. **웹훅 주소 등록**
   저장소 → Settings → Secrets and variables → Actions → New repository secret
   - Name: `DISCORD_WEBHOOK_URL`
   - Secret: 1번에서 복사한 주소
   (웹훅 주소는 코드에 직접 넣지 마세요. 누가 보면 채널에 메시지를 보낼 수 있어요.)

4. **실행해보기**
   저장소 → Actions → 공지사항 알림 → Run workflow
   - 경영경제융합학부(sobe), 사회복지학(ssw) 공지사항이 설정되어 있어요.
   - 첫 실행은 기존 글을 저장만 하고 알림은 보내지 않아요.
   - 로그에 `글 0개 확인`이 나오면 그 사이트 구조가 바뀐 거라 `post_pattern` 수정이 필요해요.

## 자주 바꾸는 설정

- **키워드만 알림**: `"keywords": ["공모전", "장학", "대회"]`
- **게시판 추가**: `BOARDS`에 블록 하나 더 추가 (`post_pattern`은 글 주소에서 글 번호를 뽑는 정규식)
- **실행 주기**: `notice.yml`의 cron (예: 30분마다 `*/30 * * * *`)

## 참고

- GitHub은 저장소에 60일간 활동이 없으면 예약 실행을 멈춥니다. 이 봇은 새 글이 생길 때마다 커밋하므로 보통 문제없지만, 멈추면 Actions 탭에서 다시 켜면 돼요.
- 예약 실행은 GitHub 사정에 따라 몇 분~수십 분 늦어질 수 있어요.
- 학교 서버에 부담을 주지 않도록 주기는 30분 이상을 권장해요.

## 디스코드 연결 테스트

Actions → 공지사항 알림 → Run workflow → **디스코드 연결 테스트 메시지 보내기** 체크 → Run.
최신 공지 하나가 `[연결 테스트]` 제목으로 디스코드에 와요. 이미 본 글 기록은 바뀌지 않아요.
